# RecoverIA Phase 4 Truth Set

Ten deterministic cases cover: largest balance with active promise; medium balance with missed promise; small ambiguous entity; disputed invoice; missing contact; 90-day stale contact; configured legal threshold; four overdue invoices; conflicting evidence; and current/no-action. An eleventh foreign-tenant case tests exclusion.

Expected action, tier, required reasons/blockers, and excluded unsafe actions are declared per scenario. Total synthetic case balance is ARS 13,200,000. The largest case is ARS 5,000,000 but has NO_ACTION due to an active promise; the oldest is the 1,500-day legal-review case. All values and explanations reference explicit fixture evidence.
